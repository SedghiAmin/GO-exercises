# Lasagna Exercise (Go)

This project is a solution to an Exercism Go exercise focused on basic functions, slices, and calculations using a lasagna recipe example.

## Features

The program implements the following functions:

- **PreparationTime**  
  Calculates total preparation time based on the number of layers and time per layer (defaults to 2 minutes if not provided).

- **Quantities**  
  Determines the required quantities of noodles (grams) and sauce (liters) based on the recipe layers.

- **AddSecretIngredient**  
  Copies the secret ingredient from a friend's recipe into your own recipe.

- **ScaleRecipe**  
  Scales ingredient quantities from a two-portion recipe to any desired number of portions.

## Example Usage

The `main` function demonstrates how each function works with sample data and prints the results to the console.

## Technologies

- Language: Go
- Concepts: slices, loops, conditionals, functions

## Notes

This exercise is designed to practice Go fundamentals and idiomatic slice handling.
